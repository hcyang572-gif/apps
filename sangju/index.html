01/05찾기

홈 · 분야별로 찾기
02/05분야

분야를 누르면, 그 분야만.

청년 분야라면 청년 사업만 모아서 보여 드려요. 카드마다 담당 팀이 적혀 있고, 바로 신청할 수 있어요.

기본순 · 최신순 · 팀별순 정렬
03/05맞춤

나이와 상황만 알려 주세요.

신혼, 임신·출산, 귀농·귀촌, 구직처럼 19가지 상황 중 해당하는 것을 고르면 맞는 분야의 사업을 찾아 드려요.

나에게 맞는 사업 찾기
04/05자세히 · 신청

무엇을, 누가, 어떻게.

지원 내용·지원 대상·이용 방법·필요 서류를 한 화면에. 담당 팀 전화로 바로 묻거나, 휴대폰에서 바로 신청하세요.

신청 그 다음

신청하고 끝이 아니에요.
어디까지 왔는지 보여요.

  1. 하나휴대폰으로 신청이름·연락처·읍면동을 적고, 필요하면 증빙서류를 붙여요.
  2. 둘접수번호와 확인 번호신청을 마치면 바로 받아요. 확인 번호는 비밀번호처럼 나만 간직해요.
  3. 셋담당 부서가 바로 확인신청은 공무원용 화면에 곧바로 나타나 접수·심사가 이어져요.
  4. 넷내 신청 현황진행 상태와 담당 부서 안내문을 확인해요. 이름·연락처는 화면에 나오지 않아요.

누구나 쉽게

어르신도, 처음 쓰는 분도.

  1. 01가글자를 크게.위쪽 「가」 단추를 누르면 모든 글자가 125%로 커져요. 휴대폰 글자 크기 설정도 그대로 따라갑니다.
  2. 02어려운 말 대신 쉬운 말.「어떤 지원이 필요하세요?」처럼 묻고, 아래 메뉴는 홈·맞춤 찾기·정책제안·내 신청 네 가지뿐이에요.
  3. 03화면 읽기 프로그램과 키보드로도.전자정부 웹 품질 기준(KWCAG 2.2)에 맞춰 점검했어요. 글자와 바탕의 명도 대비도 4.5:1 이상입니다.
  4. 04주민등록번호는 묻지 않아요.신청에 꼭 필요한 것만 받고, 진행 상태를 볼 때는 이름·연락처 대신 확인 번호를 써요.
